# Reconstructed Git history

This repository history was **reconstructed from a single supplied project snapshot**, not recovered from the original development log. Its commit order groups existing files by feature, and its commit timestamps are illustrative, spaced 7–10 minutes apart. They **do not represent actual times when the original code was written**.

The supplied archive contains an older `backend` + `cms` + `frontend` template; it does not include the later roommate functionality or `cms/src/seed.ts` discussed separately.

Files containing local secrets (`.env`) and dependencies (`node_modules`) were intentionally excluded. No original application source file was modified; only root `.gitignore` was strengthened and this disclosure file was added.

Before deployment, the CMS environment example and Vercel configuration should be reviewed against the actual current application. This reconstruction is not a substitute for running builds and tests.
